# 有界并行嵌套循环连接

## 设计

支持已有 INNER/CROSS 连接的并行合并与谓词计算。每次固定一行左输入，从右输入
最多读取 1024 行，ordered_map 并行计算 Tuple 合并及 ON 条件，按右输入顺序
输出结果。右侧扫描结束后换下一行左输入并重新 init 右侧。保持左优先顺序、
重复值和常量内存批次；不物化整个右表或连接结果。页读取与子算子的 next/init
都在调用线程运行。workers=1 使用相同状态机但批次大小为 1，保留按需消费。

状态包括当前左行、右侧结束标记、整体结束标记和 Result 队列。普通谓词错误
按候选对顺序进入队列，输入错误在已有结果后返回。读取完右侧一批且无匹配时
继续；整体 EOF 之后不重新扫描，init 清空全部状态。LIMIT 提前结束时释放批次。
NULL ON 条件视为不匹配，非布尔条件返回 Execution 错误。尚未实现的 OUTER
连接必须明确返回 NotSupport，不能继续用 INNER 的结果误导调用者。

Values 算子的 init 补充游标清零，确保连接右侧含 VALUES 时可以重复扫描。
这是连接状态机的必要依赖，不改变 VALUES 单次执行结果。

## 测试

对 1/2/4 线程比较 INNER/CROSS、空侧、无匹配、多批右侧、重复键、LIMIT 和
子查询结果。算子覆盖 VALUES 重初始化、反复 EOF、init 重用、NULL ON 和
不支持的外连接错误。计划验证启用并行连接而写计划仍串行。全部工作区测试、
fmt 与 diff 检查通过后独立 commit/push。
