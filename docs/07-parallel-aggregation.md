# 并行 COUNT / AVG 聚合

## 设计

每批读取最多 1024 条输入，以连续分片交给工作线程。每个线程独立维护
HashMap<分组键, 累加器>，对 COUNT 和 AVG 求局部结果；调用线程按照分片顺序
将局部累加器状态合并到全局分组表。分组键和聚合参数均由工作线程求值。
workers=1 采用同一路径的一个分片，不创建工作线程。查询计划显示并行度，
写语句继续串行。输入内存有界，但分组状态仍随不同键的数量增长，不提供 spill。

Accumulator 增加类型化可合并状态：Count(i64)、Avg { sum: Option<f64>, count: u64 }。
AVG 合并总和与非 NULL 计数，绝不直接平均分片均值；NULL 不增加计数。错误状态
类型返回错误。COUNT 和 AVG 计数使用 checked_add。浮点加法分组顺序可能导致
最后几位舍入差异，测试使用精确可表示值及容差，不承诺浮点逐位一致。

## 状态生命周期和语义

init 清空输出、游标及 built 标志，重新 init 输入。聚合必须消费全部输入才能
返回，任何输入/表达式/累加错误终止查询，不公布部分聚合。built 区分“尚未执行”
和“执行后零行”，避免空分组重复读输入。无 GROUP BY 的空输入仍产生一个分组，
COUNT=0、AVG=NULL；有 GROUP BY 的空输入返回零行。未 ORDER BY 的分组顺序未定义。

## 验证

比较串行与 2/4 线程的跨批 COUNT/AVG、GROUP BY、NULL、全 NULL、空输入、
不均匀分片（验证加权平均）、过滤后聚合及重复初始化。累加器单测验证合并类型
校验、NULL 状态与溢出处理。SQL 套件双模式执行。全部测试、fmt/diff 通过后
独立提交推送，并将 Parallel Execution 标注为当前支持算子的并行执行已实现，
明确索引扫描和磁盘 I/O 仍串行、外连接未实现。
